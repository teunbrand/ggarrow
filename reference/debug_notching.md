# Debug tool for shaft notching

This is a low-level tool to debug the notching of arrow ornaments onto
arrow shafts.

## Usage

``` r
debug_notching(ornament, width = 0.2)
```

## Arguments

- ornament:

  An [arrow
  ornament](https://teunbrand.github.io/ggarrow/reference/arrow_ornaments.md).

- width:

  A `numeric(1)` value for the line's width.

## Value

A `list` with `x` and `y` elements.
